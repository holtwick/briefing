# Changelog

All notable changes to the Briefing app for Nextcloud. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); the version heading must match
`appinfo/info.xml`.

## 0.1.0

### Added

- Briefing entry in the app menu with one's own rooms and those shared with one's groups.
- Create a room with a name, optionally shared with one group, moderated by default, as video call or chat.
- The owner joins a moderated room as moderator and copies the link for guests; group members join as participants.
- Admin setting for the Briefing instance (empty: the official instance `https://brie.fi/ng/`).
- Rooms of a deleted user are deleted with them.
